# نواقص المكتبة

أبلكيشن لتسجيل نواقص المكتبة أول بأول، مقسمة على المراكز (النصرية، الممر، الشقة)، وإرسال الكشف للمخزن على واتساب أو كملف PDF.

- **الرابط:** https://ahmedn99005-oss.github.io/Nawaqes/
- **التثبيت على أندرويد:** افتح الرابط في Chrome، ودوس «ثبّت الأبلكيشن» اللي فوق، أو من قايمة ⋮ اختار «تثبيت التطبيق».
- **أوفلاين:** الأبلكيشن بيشتغل من غير نت خالص بعد أول مرة يتفتح.
- **البيانات:** محفوظة على الموبايل نفسه بس، مفيش سيرفر ولا تسجيل دخول.
  - اعمل «نسخة احتياطية» من الإعدادات كل فترة وابعتها لنفسك على واتساب أو Drive.
  - لو غيرت الموبايل أو مسحت بيانات Chrome، رجّع بياناتك بـ«استيراد ملف».

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | شكل الأبلكيشن |
| `app.js` | كل شغل الأبلكيشن: النواقص، المراكز، قاعدة الأصناف، البحث، الكشف، الـPDF، النسخة الاحتياطية |
| `store.js` | حفظ البيانات على الجهاز |
| `sw.js` | بيخلي الأبلكيشن يتثبت ويفتح من غير نت |
| `manifest.webmanifest` و`icons/` | اسم الأبلكيشن وأيقونته على الموبايل |

## التحديثات

أي تعديل يتعمل في الـrepo ده على فرع `main` بيتنشر لوحده على GitHub Pages في حوالي دقيقة، والأبلكيشن بياخده أول مرة يتفتح والنت شغال. البيانات اللي على الموبايل مابتتأثرش بالتحديثات.
